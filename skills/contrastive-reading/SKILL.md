# Contrastive Reading

## 这个 skill 在做什么

研究者读文献慢，不是因为读得不够细，而是因为每篇论文都被当作孤立对象从头理解一遍。但一个有经验的研究者脑子里已经有一张地图——他熟悉的那几篇论文就是地图上的坐标。真正需要传输给他的，只有**新论文相对于这张地图的位移**。

所以本 skill 的产出不是"这篇论文讲了什么"，而是"相对于你已经知道的，这篇论文改变了什么"。读者只需要关注差异化的内容，literature review 的速度自然就上来了——加速是这个方法的**结果**，不是目标；目标始终是把差异刻画准确。

而"改变了什么"要成立，必须先有一条两篇论文都站在上面的轴。**因此这个 skill 的重心始终压在可比差异上**：只有可比的位移才能告诉读者他的哪个既有认知需要更新、该精读哪一节。不可比的部分是必要的护栏，但不是主菜。

**明确不做的事**：不写摘要，不复述 abstract，不做"本文提出了一种新方法……"式的概括。如果输出里出现了脱离锚点的独立段落式介绍，说明走偏了。用户对这个领域的背景知识远超一份摘要能提供的内容，重复它是纯粹的浪费。

## 参与对比的论文

- **锚点集（anchor）**：用户已经熟悉的论文，1 篇或多篇。这是坐标系原点。
- **目标集（target）**：用户想快速判断的新论文，1 篇或多篇。

四种常见形态都要支持：1 对 1、1 对多（一个锚点、多篇新论文横向筛选）、多对 1（多个锚点共同定位一篇新论文）、多对多。当目标集 > 1 时，除了每篇对锚点的差异，还要做**目标之间的横向差异**——用户往往是在做筛选，需要知道这几篇彼此的关系（互补、重复、竞争、还是同一想法的不同包装）。

## 第零步：把输入问齐

本 skill 是被显式调用的，所以用户往往只是丢过来一个链接就说"对比一下"。两集之中缺任何一个，整个方法就不成立——**不要靠猜，也不要退化成单篇概括**。缺什么就问什么，一次问完：

- 缺锚点 → "以哪篇（或哪几篇）你已经熟悉的论文作为参照？给标题就行。"
- 缺目标 → "要对比的新论文是哪几篇？arXiv 链接、DOI 或本地 PDF 路径都可以。"
- 两者都有但角色不清 → 直接确认哪边是熟悉的、哪边是要判断的。
- 顺带问阅读目的（如果上下文里不清楚）：是在找可复用的方法、判断自己的工作是否被 scoop、写 related work、还是追一条技术路线的演化？目的不同，"值得读"的判据完全不同。

把这些问题合并成一轮问完。用户是主动调用这个工具的，他期待的是一次交互就进入正题，而不是被挤牙膏式地追问三轮。

例外：如果对话上文里已经明确出现过用户熟悉的参照论文，可以直接用它，但要在简报开头一行写明"本次以 X 为锚点"，让用户能立刻纠正。

## 第一步：校准锚点

后续所有输出都建立在锚点之上，锚点理解错了整份简报就是废的。所以在动手对比之前：

- **如果锚点只给了标题**：先用一到三句话复述你对它的理解——核心主张、关键设置、它当年解决的痛点——请用户确认或纠正。这一步很快，但能挡住最贵的错误。如果对这篇论文没有可靠记忆，直接说不确定并去检索摘要，不要凭标题猜内容。
- **如果锚点给了全文**：不需要向用户确认，但要自己先提取出锚点在各个维度上的立场，作为对比基准。
- **无论哪种情况，锚点的全文都要取回来**。因为后面每个对比点都必须贴双方原文（见"强制要求"一节），光靠对锚点的记忆是贴不出可搜索的引文的。用户确认锚点身份之后，按第二步的路径把它也解析一遍。

## 第二步：获取论文

差异分析的分辨率受限于解析质量。公式被打散、表格被压平、多栏被串行读取，都会让第三步的坐标轴建不起来——所以解析路径的选择不是细节。

- **arXiv 链接 / arXiv ID**：优先取 `arxiv.org/abs/<id>` 拿标题摘要，再取 HTML 全文（arXiv 自带 HTML 渲染或 ar5iv）。HTML 版的公式和结构远好于从 PDF 抽文本，能拿到就不要走 PDF。
- **DOI / 期刊页**：解析到出版商页面。遇到 paywall 就明确告诉用户拿不到全文，并说明当前简报只基于摘要和可获取部分——不要在证据不足时假装读过全文。
- **本地 PDF / 拿不到 HTML 的 arXiv 论文**：走 `mineru-sciverse` skill（同一 toolkit 内）。单篇用本地 `pdf2md paper.pdf`（也直接吃 URL：`pdf2md https://arxiv.org/pdf/<id>`），批量或大文件用 `mineru-cloud` MCP 的 `parse_documents`。它把公式还原成 LaTeX、表格还原成 HTML、修正多栏阅读顺序，正是差异分析需要的保真度。两条路互为兜底，具体取舍见该 skill。
- **只有标题、需要先找到论文**：`mineru-sciverse` 的 `sciverse` MCP（`search_papers` / `semantic_search`）可以定位论文并取回元数据，再把 PDF 喂回解析。锚点论文只给了标题时尤其有用。
- **降级路径**：上述都不可用时退回普通 PDF 文本抽取，但要在输出的「待确认」里注明公式/表格可能有解析损失，并避免基于这些部分下强结论。

阅读全文时，投入应当不均匀：**方法/建模章节、实验设置（不是实验结果表格本身）、假设与限制声明**要读透，因为差异藏在这里；intro 和 related work 快速扫过即可，它们主要告诉你作者想把自己放在哪个位置——这个信息有用，但不要被作者的自我定位牵着走。

## 第三步：建立共同坐标轴

这是整个流程的枢纽，也是最容易跳过而导致输出退化成两段摘要的地方。

在写任何差异之前，先在内部列出这些论文共同触及的维度。典型的轴包括但不限于：要解决的问题、问题的形式化方式、核心假设、方法机制、理论保证、数据与实验设置、评价指标、计算代价、失效条件、适用边界。不要套用固定清单——不同子领域的关键轴差别很大，从论文本身长出来的轴才有信息量。

然后逐轴判断：**这两（几）篇在这条轴上的取值，能不能放在一起比？**

**在这一步要用力找可比的轴，而不是急着分类。** 一条轴看起来不可比，往往只是因为你停在了作者使用的术语层级上。抬高一档抽象层级再问一次：两篇论文是不是在回答同一个更一般的问题？"如何防止模型拟合到不该拟合的东西""什么东西提供了归纳偏置""保证来自哪里"——这类轴常常能把表面上毫不相干的两篇论文接上，而接上之后的对比正是读者真正想要的。

判断依据是**能否互相翻译**，不是术语是否相同、领域是否相同。术语不同但机制同构 → 可比；术语相同但测量方式不同 → 不可比（错轴型）。这两种情况都很常见，且都与直觉相反。

## 第四步：可比差异是主体，不可比差异是配角

这个二分是本 skill 的核心，但**两边的权重完全不对等**。

**可比差异是这份简报的主体，也是全部价值所在。** 读者要的是"在同一条轴上，新论文把位置挪到了哪里"——这是他能直接用来更新认知、写进 related work、决定要不要复用的东西。可比差异应当占据输出的绝大部分篇幅和你绝大部分的分析努力。

**不可比差异是配角，只承担两件事**：(1) 防止读者被假可比误导（错轴型）；(2) 标出新论文的贡献本体落在哪个空位（缺位型）。它不是"另外一半内容"，写不满是正常的，写得比可比差异还长则几乎肯定是走偏了。

### 可比差异（主体）

存在一条共同的轴，各篇都在这条轴上取了明确的值，且取值方式可以互相翻译。判据：把 A 的做法放进 B 的设置里描述一遍，这句话是否有意义？有意义就是可比的。

呈现方式：并置。轴 → 锚点的取值 → 目标的取值 → 差异的量级和方向。能量化就量化，量化不了就说清楚是定性判断。

每条可比差异都要回答"所以呢"——这个位移意味着读者的哪个既有认知要改、哪个做法可以换、哪个结论不再适用。只报位移不报后果，读者还得自己再想一遍，等于没省下时间。

### 不可比差异（配角，从简）

- **错轴型**（必须报）：两边用了同一个词，但定义或测量方式不同——都叫 accuracy 但数据划分不同，都叫 robustness 但威胁模型不同，都叫 efficiency 但计入的成本项不同。这类差异**看起来最可比，实际上是范畴错误**，直接对比数字会得出完全错误的结论。这是不可比差异里唯一必须无条件报告的一类，因为不报读者就会自己错误地比一遍。
- **缺位型**（简报）：一方有某个组件/概念/结果，另一方连对应的位置都没有。一句话说清它填的是哪个空位即可，不要展开成小论文。
- **前提型**（尽量少用）：假设空间不重叠。这一类最容易被滥用成偷懒的出口——在写下"前提不重叠"之前，先回第三步再试一次抬高抽象层级。真正的前提型不可比是少数情况，不是默认结论。

呈现方式：不要强行并置成表格，那本身就是在制造错觉。

### 两条纪律

**不要为了填满结构而制造差异。** 如果两篇论文的实质差异很小、区别主要在术语和包装上，直接这么说——"核心机制等价于锚点论文的 X，重新命名为 Y，实质增量是 Z"。这个结论对用户的价值极高，且只有做过认真对比的人才敢下。

**如果穷尽努力后可比的轴确实极少**（比如两篇论文分属完全不同的研究谱系，互不引用、无共同问题），那就早点说清楚并停下：一句话讲明它们为什么接不上、在哪个抽象层级上还能勉强对照，然后结束。不要用一份结构完整、篇幅饱满的报告来掩盖"这次对比本身不成立"这个事实——那是在浪费读者的时间，而节省时间正是这个工具存在的理由。

## 第五步：冲突与改进

"特别值得关注的地方"不是一个独立的杂项抽屉，它就是差异里张力最大的那些点。只有两类：

**冲突**——一方成立会削弱另一方。包括：经验数字直接打架（同一设置下结论相反）；建模假设互斥；一方的失效分析恰好命中另一方的核心机制。冲突点是最值得用户亲自去读原文的地方，因为往往两边都没错，是某个未被言明的条件在起作用——找出那个条件通常就是一个研究机会。

**改进**——在某条可比轴上严格更好。发现改进之后必须继续追问三件事，否则这份简报就只是在替作者转述宣传：

1. 这个改进是**机制**带来的，还是**设置**带来的？（更强的 baseline、更多的数据、更细的调参、更宽松的评测协议，都能制造"改进"）
2. 有没有**未被报告的代价**？在某条轴上变好，通常伴随另一条轴变差——如果论文没提，那条轴大概率就是代价所在。
3. 消融实验是否真的隔离了被声称的那个因素？

批判性审视就体现在这里，而不是单独开一节"局限性"。同时保持公允：指出可疑点之后，如果作者有合理的辩护空间，一并给出——目的是让用户自己判断，不是替他下结论。

## 强制要求：每个对比点都要贴原文

这是本 skill 不可省略的部分。**每一个对比点，都要把双方的论文原文摘出来放在旁边。**

理由很实际：读者拿到简报后要能立刻回到原论文验证。一句你自己写的转述，他没法在 PDF 里搜；一段逐字的原文，他复制粘贴就能定位。这一条同时也是对你自己的约束——如果一个差异你摘不出支撑它的原文，说明那个差异很可能是你脑补的。

规则：

- **逐字引用，不改写、不润色、不翻译**。任何改动都会让搜索失败，这就毁掉了引文的全部意义。需要翻译或解释就放在引文后面，引文本身保持原样。
- **两边都要贴**。可比差异贴双方对应段落；不可比差异里的缺位型只有一方有文本，那就贴存在的一方，并明说另一方全文中没有对应表述（这本身就是证据）。
- **长段落用省略号截断，但开头必须留一段完整连续的原文**作为可搜索的锚句——大约一句到两句。中间省略写作 `[…]`，结尾可以停在任意位置。宁可留长一点，也不要截到搜不到。
- **附定位**：§ 章节号 / Table N / Eq. (N) / Fig. N，写在引文后面。
- **公式**：用 LaTeX 呈现，并注明来自哪个式子编号。若解析质量存疑，明确标出。
- **摘不出原文时**：不要硬编。要么去把原文找回来，要么把这条明确标为"推断，无直接文本支撑"并降低它在简报中的权重。

格式建议（保持紧凑，不要让引文淹没结论）：

```
**轴：<差异维度>**
- 锚点《X》：<你的一句话判断>
  > "verbatim sentence from the paper […] continuing verbatim" — §3.2
- 目标《Y》：<你的一句话判断>
  > "verbatim sentence […] verbatim" — §4.1, Eq. (7)
```

## 输出

直接在对话中输出，不写文件（除非用户明确要求）。语言跟随用户，数学公式用 LaTeX 渲染。

按这个骨架组织，但可以根据实际情况增删——比如没发现任何冲突就不要硬编一个：

```
## 判断：值不值得读，读哪里
一句话结论 + 阅读路线（精读哪几节 / 略读 / 可跳过），按优先级排序
每一条路线项都要挂在某条可比差异上：读 §X，因为轴「<某维度>」上的位移在那里

## 可比差异（主体）
逐轴并置：轴 → 锚点立场 + 原文引用 → 目标立场 + 原文引用 → 差异方向与量级 → 所以呢
按重要性排序，重要的多写，次要的一两行带过

## 不可比差异（从简）
错轴型必报；缺位型一句话；前提型能不写就不写
每条：差异内容 + 双方原文（缺位型贴存在的一方并说明另一方无对应表述）→ 为什么不能直接比

## 冲突点
每条：冲突在哪 → 双方各自的原文依据（这里的引用尤其重要，冲突必须让读者自己看原话判断）
→ 可能的调和条件

## 实质改进
每条：改进了什么 + 原文声明 → 机制性还是设置性 → 代价在哪 → 证据强度

## 目标之间（仅当目标 > 1 篇）
它们彼此是互补 / 重复 / 竞争 / 同一想法的不同包装 → 读哪几篇就够，为什么

## 待确认
证据不足、解析可能有损、或需要用户自己核对的点
```

**阅读路线必须从可比差异导出。** "值得读"不是一个独立的整体印象，而是可比差异的直接推论：某条轴上的位移越大、越出乎读者基于锚点的预期，承载它的那几节就越值得精读；在锚点已覆盖的轴上没有位移的章节，就是可以跳过的部分——这正是差分阅读省时间的机制所在。所以路线里的每一项都应该能指回上面某条具体的轴。挂不上任何轴的"建议精读"，说明那是凭印象给的，删掉。

**区分事实与推断**：从原文读到的、你从原文推断的、你不确定的，三者要能被用户一眼分开。宁可说"不确定"，也不要用流畅的语气填补空白——研究者最怕的就是被一份自信的错误简报带偏。

## 常见失败模式

- **退化成摘要**：输出里出现了不引用锚点的独立介绍段落。修正方式是回到第三步，先把轴列出来。
- **把"不可比"当逃生舱**：一旦宣布不可比，就不必再费力找共同轴了——这是最舒服也最没价值的偷懒方式，而且它会连带毁掉阅读路线（没有可比差异，"值得读哪里"就失去了依据，只能退化成一句空泛的元评论）。判断标志：不可比差异的篇幅超过了可比差异。出现这个信号就回第三步，抬高一档抽象层级重找。
- **阅读路线与可比差异脱钩**：给出"建议精读 §3"却说不出对应哪条轴上的位移。这种建议是凭整体印象编的，读者照做也省不下时间。
- **把不可比的东西并置成表格**：表格天然暗示可比，用它承载错轴型差异会直接误导用户。
- **转述作者的自我定位**：论文的 intro 和 related work 是作者的叙事。你的工作是独立判断新论文相对于**用户的**锚点在哪，而不是相对于**作者选的** baseline 在哪。这两者经常不一致，而不一致本身就是重要信息。
- **多篇目标时只做纵向不做横向**：用户在筛选时，最想知道的常常是"这三篇我读哪一篇就够了"。
- **平均用力**：每条差异都写三行。实际上差异的重要性差几个数量级，输出的篇幅应该反映这一点。
- **引文被改写**：把原文顺手润色、翻译、或"整理"成更通顺的句子——读者就再也搜不到它了，引文的全部价值瞬间归零。宁可贴一段拗口的原句。
- **只贴一边的原文**：只引用目标论文、锚点那边靠记忆转述。这样读者无法对称核对，而记忆恰恰是最容易出错的一环。
